# Code of Conduct

We want Migrate Anything to be a welcoming project for everyone.

## Expected behaviour

* Be respectful and constructive; assume good intent.
* Critique code and ideas, not people.
* Respect privacy: never post credentials, customer data or confidential documents in issues,
  pull requests, logs or test fixtures.

## Unacceptable behaviour

Harassment, discrimination, personal attacks, sexualized language or imagery, publishing others'
private information, and sustained disruption.

## Enforcement

Report concerns privately to the maintainers (contact to be published with the repository).
Maintainers may remove content and restrict participation. This code applies in all project
spaces. It is adapted in spirit from the Contributor Covenant.
