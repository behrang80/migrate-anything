# Declarative connector specification (spec_version 1)

Generated by `connectors generate` from OpenAPI 3.x, or written by hand and registered with
`connectors register-spec`. Interpreted by the trusted REST runtime; it cannot contain code,
hosts or secrets. Unknown fields are rejected.

```json
{
  "spec_version": 1,
  "connector_id": "fieldops-legacy",
  "version": "1.0.0",
  "protocol": "rest",
  "title": "FieldOps Legacy Service",
  "api_version": "2.4.1",
  "base_path": "/api/v2",
  "authentication": { "type": "api_key_header", "header": "X-Api-Key" },
  "rate_limit": { "max_requests_per_second": 20, "respect_retry_after": true },
  "resources": [{
    "name": "technicians",
    "identity_field": "tech_id",
    "list":   { "path": "/technicians", "records_path": "items",
                "pagination": { "type": "cursor", "cursor_param": "after", "next_cursor_path": "next_cursor",
                                "limit_param": "limit", "page_size": 100 } },
    "create": { "method": "POST", "path": "/technicians", "response_id_path": "", "idempotent": false },
    "get":    { "path": "/technicians/{id}" },
    "lookup": { "path": "/technicians", "query_param": "tech_id", "key_field": "tech_id", "records_path": "items" },
    "fields": [ { "name": "tech_id", "field_type": "string", "required": true } ],
    "relationships": []
  }],
  "provenance": { "generated_by": "connector-factory/openapi@1.0.0-rc.1", "generated_at": "…",
                  "source_document_sha256": "…", "notes": ["…"] }
}
```

* `authentication.type`: `none`, `bearer`, `api_key_header` (`header`), `basic` (credential `user:password`).
* `pagination.type`: `none`; `cursor` (`cursor_param`, `next_cursor_path`, `limit_param?`, `page_size`);
  `offset` (`offset_param`, `limit_param`, `page_size`); `page` (`page_param`, `size_param?`, `page_size`, `first_page`).
* Methods: create `POST|PUT`, update `PUT|PATCH` with `{id}`; `DELETE` is never allowed.

## Validation rules
Paths start with `/`; no `://`, `..`, `?`, `#`, `@`, `\`, `//`, encoded dots, whitespace; the only
placeholder is `{id}`; page sizes 1–1000; header names restricted (no `Host`, `Cookie`, …);
`connector_id` `[a-z0-9-]{3,64}`; `version` `MAJOR.MINOR.PATCH`; unique resource names.

## Lifecycle
`draft` (generated + statically valid) → `tested` (read-only contract tests pass: connection,
read, schema conformance, pagination advance without repeats, lookup) → `active` (operator
activation; required to write to the system) → `disabled`. Specs are content-hashed; a modified
spec is refused at load. A document identical to an already registered one reuses that connector.

## What the generator infers
Collections (`GET` without path params returning an array or an object with an array property),
items (`/{param}`), create/update operations, identity field (item path param, `id`, or a required
`*_id/_number/_key/_code`), pagination parameters and next-cursor fields, auth scheme, field types
(`number` → exact decimal unless `float/double`), enums, `readOnly`, custom fields (`x_`, `cf_`,
`custom_` prefixes), relationships (`<identity>`/`<resource>_id` names or descriptions naming
another resource's identity field — evidence `inferred`). Text that addresses AI agents is
reported in `suspicious_text` and withheld from the spec.
